Export request specification - Example Precision Works, Plant 1 (EPW1)

For the plant's IT. Written 2026-11-15 because these sources were not in hand at setup. Each file lets the plugin's scheduled skills run without a live connector.

Rules for every file

  • Format: CSV, UTF-8, header row, comma-delimited, text fields quoted.
  • Landing path: the SharePoint "Exports" library folder the MES already writes to (exact folder to be confirmed).
  • Naming: <source>_<entity>_<YYYY-MM-DD>.csv, dated the day of export.
  • Cadence: nightly, landing by 23:45 local, alongside the 23:30 MES file - or a later fixed time, stated.
  • Timestamps: ISO 8601 with offset (2026-11-13T14:30:00-05:00). Bare local times break cross-system correlation.
  • Late or corrected records: re-export the full rolling window every night; the newest file wins on the record key.
  • Every row: a site column = EPW1.
