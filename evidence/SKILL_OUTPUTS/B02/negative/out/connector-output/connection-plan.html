7. How it will break (Step 12)

  • Schema drift: a CMMS upgrade renames a column; the query returns wrong or empty data with no error. Probe re-run on every change; owner: CMMS/database administrator (role).
  • File moved or replaced: path breaks — exactly what happened in this run. Detection: probe exit code 2.
  • Lock contention: reading a file the CMMS is writing may return a busy error.
  • Staleness: if this is a copy rather than the live database, freshness is whenever it was copied; data-consolidate's freshness check applies.
