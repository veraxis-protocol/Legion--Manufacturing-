5. Credentials and scope (Step 6)

No credential exists or was used: the SQLite file has no login, and access is the file-system read permission. Read-only was enforced on the connection (mode=ro, PRAGMA query_only=ON), a write probe was refused, and the file's sha256 and modified time were identical before and after. mode=ro is a client setting, not enforcement: grant a dedicated integration service account read-only file permission. Write scope: none requested, none granted. A Claude skill produces artifacts; it does not stand up or host infrastructure. Record: credential-scope-record.json.
